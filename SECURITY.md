# Security

Please don't report security problems in public issues. Report them privately on GitHub instead: [Report a vulnerability](https://github.com/f1n3d/diderot/security/advisories/new) (Security tab › Report a vulnerability). Only you and the maintainer see the report until it's fixed.

Fixes go into the newest version of Diderot. Problems in Docmost itself, its server or web app, belong to the [Docmost project](https://github.com/docmost/docmost).
